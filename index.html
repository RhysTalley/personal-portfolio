Remote TLS Certificate Expiration Monitor

CC++x86 ASMz/TPF
ProblemLarge z/TPF clients — Visa, Amtrak, the IRS — had no way to track expiry of the remote TLS certs their systems handshake with. A silent expiration means an outage.
BuiltCompliance tooling that captures client/server certs after the TLS handshake into a hashmap in system heap. An operator command lists every stored cert with its expiry; a daily sweep flags anything inside a configurable window and hands it to a customizable user exit so each client wires in their own alerting.
Hard partDoing this inside a proprietary OS with tight heap constraints and zero tolerance for leaks — and designing the user-exit boundary so clients extend behavior without touching core code.

Parallel I/O & Compression Migration

CC++TPFDFCRUISE
ProblemA hierarchical, record-oriented TPFDF database was slow to read at scale.
BuiltA migration routine converting it into an indexed, compressed structure — up to 96% faster reads. Reused existing CRUISE architecture and DF APIs to keep duplication down, plus a fallback path so a migration can roll back safely on live data.
Hard partMaking migration safe and reversible against production data while proving the read-path win held up under real load.
